Baani AI Desktop 1.0.8 — Early Access

Use the same Baani account and online workspace, with a system-wide shortcut and floating dictation widget.

This update replaces the dictation overlay with a tiny, microphone-reactive waveform pill. Press the shortcut again to process, insert and dismiss immediately. Desktop settings can record custom shortcuts, including Ctrl+Windows on Windows. Normal dictation has no branding, text or buttons; recovery controls appear only after a failure so text and retryable audio remain available. Cleanup, formatting and account word allowances continue to use the shared Baani service.

Computer audio requires explicit recording consent. Windows uses system loopback; other computer sounds may be included. Mac desktop capture requires macOS 15+ system-picker audio support and permission; physical Mac capture is not verified. Check both audio meters and use headphones. Browser users must select the meeting tab and enable Share audio. No screen video is recorded or uploaded. Microphone-only mode remains available for in-person meetings.

Windows: Ctrl+Alt+Space. Mac: Command+Shift+9. Press again to finish.

Signing and notarization status is disclosed on the download page. Mac cross-app dictation has not been verified on a physical Mac. Allow microphone access and, on Mac, Accessibility access. Internet is required.

Install Windows by running the .exe. On Mac, open the .dmg and drag Baani AI into Applications. Use /desktop inside the app for setup and updates.

Verify SHA-256 checksums with SHA256SUMS.txt. Your existing Baani plan and account allowances apply.
